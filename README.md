# Лендинг ОПИФ «Матрёшка а-ля Рус»

Одностраничный сайт фонда. Собирается одной командой в самодостаточный `index.html`
(все картинки и данные встроены — файл открывается офлайн и переносится одним куском).

## Сборка

```bash
cd matryoshka-landing
python3 build.py      # → index.html
open index.html       # открыть в браузере
```

## Что откуда берётся

| Блок | Источник | Обновление |
|------|----------|------------|
| График, доходности, СЧА, пай | `../matryoshka-tracker/matryoshka.db` | `collect.py` в трекере |
| Топ-10 эмитентов, сектора, ISIN, дата структуры | `../onepager-matryoshka/входные-данные/structure.json` | `parse_finuslugi.py` |
| Доля акций/облигаций, имя управляющего | `../onepager-matryoshka/входные-данные/параметры.yaml` | вручную |
| Лого, фото, QR (Финуслуги/Альфа) | `ассеты/` | статично |
| Документы (секция 9) | `документы/*.pdf` | кладёте PDF → пересборка |

## Структура страницы (11 секций)

1. Заставка — лого, название, тезис, кнопка «Инвестировать» + KPI-панель.
2. Об управляющем.
3. Для кого подойдёт фонд.
4. Стратегия — аллокация, топ-10 эмитентов, сектора.
5. Результаты — интерактивный график (фонд vs индекс MCFTR, переключатель интервалов
   и режима «Доходность / Стоимость пая») + таблица доходностей.
6. Преимущества инвестиций через ПИФ.
7. Как купить — 3 способа: Финуслуги, Альфа-Капитал, через брокера по ISIN.
8. СМИ о фонде — **заглушки**, заполнить.
9. Документы — авто-список из папки `документы/`.
10. Вопросы-ответы (аккордеон).
11. Контакты — **заглушки** (email/телефон/Telegram), заполнить.

## Что нужно заполнить вручную

Помечено в шаблоне комментариями `ЗАГЛУШКА` / `РЕДАКТИРУЕМО` в `build.py`:

- **Секция 2** — реальная биография управляющего.
- **Секция 8 (СМИ)** — карточки публикаций (издание, заголовок, ссылка).
- **Секция 11 (Контакты)** — e-mail, телефон, Telegram.
- **FAQ** — точные суммы минимального входа, комиссии/надбавки.

После правок в `build.py` пересоберите страницу: `python3 build.py`.
