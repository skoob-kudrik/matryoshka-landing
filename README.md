# Лендинг ОПИФ «Матрёшка а-ля Рус»

Одностраничный сайт фонда. Собирается одной командой в самодостаточный `index.html`
(все картинки и данные встроены — файл открывается офлайн и переносится одним куском).

## Сборка

```bash
cd matryoshka-landing
python3 build.py      # → index.html
open index.html       # открыть в браузере
```

## Что откуда берётся

| Блок | Источник | Обновление |
|------|----------|------------|
| График, доходности, СЧА, пай | `../matryoshka-tracker/matryoshka.db` | `collect.py` в трекере |
| Топ-10 эмитентов, сектора, ISIN, дата структуры | `../onepager-matryoshka/входные-данные/structure.json` | `parse_finuslugi.py` |
| Доля акций/облигаций, имя управляющего | `../onepager-matryoshka/входные-данные/параметры.yaml` | вручную |
| Лого, фото, QR (Финуслуги/Альфа) | `ассеты/` | статично |
| Место в рейтинге (hero + KPI) | investfunds.ru, онлайн при сборке | авто (`fetch_rank`) |
| Документы (секция «Отчёты») | `документы/*.pdf` | кладёте PDF → пересборка |

### Пути и переменные окружения

По умолчанию `matryoshka.db` берётся из соседней папки `../matryoshka-tracker/`, а
входные данные one-pager — из `данные-фонда/` (их копия в этом репозитории; если
папки нет — из `../onepager-matryoshka/входные-данные/`). Для сборки в CI пути
переопределяются переменными окружения:

| Переменная | Что задаёт | По умолчанию |
|------------|-----------|--------------|
| `MATRYOSHKA_DB` | путь к базе трекера | `../matryoshka-tracker/matryoshka.db` |
| `ONEPAGER_DIR` | папка с `structure.json` + `параметры.yaml` | `данные-фонда/` |
| `DOCS_DIR` | папка PDF-документов | `документы/` |
| `ASSETS_DIR` | папка ассетов | `ассеты/` |
| `OUT` | путь выходного файла | `index.html` |

> `данные-фонда/` — копия входных данных one-pager. Обновляйте её раз в месяц
> вместе с новым обзором (файлы `structure.json` и `параметры.yaml`), иначе состав
> портфеля/сектора на странице останутся от прошлого месяца.

## Публикация (Yandex Object Storage + CDN)

Сайт — статика: `index.html` + папка `документы/`. Хостинг — бакет Object Storage
как статический сайт, HTTPS на своём домене через Yandex Cloud CDN + Certificate
Manager. Пересборка и заливка — автоматически по будням через GitHub Actions
(`.github/workflows/deploy.yml`, 16:20 МСК + кнопка ручного запуска), либо локально
скриптом `./deploy.sh`.

**Секреты в код/репозиторий не пишем.** Локально `deploy.sh` берёт ключи из
`~/secrets.env`, в CI — из GitHub Secrets: `YC_KEY_ID`, `YC_SECRET`, `YC_BUCKET`.

Разовая настройка в Yandex Cloud (бакет → сервисный аккаунт + статический ключ →
Certificate Manager → CDN-ресурс → DNS домена) — по шагам при развёртывании.

## Структура страницы (11 секций)

1. Заставка — лого, название, тезис, кнопка «Инвестировать» + KPI-панель.
2. Об управляющем.
3. Для кого подойдёт фонд.
4. Стратегия — аллокация, топ-10 эмитентов, сектора.
5. Результаты — интерактивный график (фонд vs индекс MCFTR, переключатель интервалов
   и режима «Доходность / Стоимость пая») + таблица доходностей.
6. Преимущества инвестиций через ПИФ.
7. Как купить — 3 способа: Финуслуги, Альфа-Капитал, через брокера по ISIN.
8. СМИ о фонде — **заглушки**, заполнить.
9. Документы — авто-список из папки `документы/`.
10. Вопросы-ответы (аккордеон).
11. Контакты — **заглушки** (email/телефон/Telegram), заполнить.

## Что нужно заполнить вручную

Помечено в шаблоне комментариями `ЗАГЛУШКА` / `РЕДАКТИРУЕМО` в `build.py`:

- **Секция 2** — реальная биография управляющего.
- **Секция 8 (СМИ)** — карточки публикаций (издание, заголовок, ссылка).
- **Секция 11 (Контакты)** — e-mail, телефон, Telegram.
- **FAQ** — точные суммы минимального входа, комиссии/надбавки.

После правок в `build.py` пересоберите страницу: `python3 build.py`.
